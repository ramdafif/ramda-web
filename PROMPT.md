# RAMDA Personal Website — implementation brief

Source: the owner's master build prompt supplied on 30 October 2026. This file records the implementation scope; the owner's original conversation remains authoritative.

Build from zero in `ramdafif/web-pribadi`, targeting branch `web-pribadi/NEW`, without referring to or reusing main-branch code. Astro SSR + TypeScript + Tailwind + Node standalone frontend, Flask/Python 3.12 backend, SQLAlchemy, migrations, Pydantic, server-rendered Jinja/HTMX/Alpine admin. SQLite local, MySQL/MariaDB production. No Redis, vector DB or Docker requirement. Preserve supplied RAMDA logo references and a mobile-first premium dark/bronze visual system.

All marketing content is database-driven and editable in `/admin`; initial copy belongs only in `backend/seed/content.json`. Localized `{id,en}` schemas support a later EN switch. Implement SiteSettings, SectionConfig, Hero, Stat, Project, Service, Package, ProcessStep, TechItem, About, Testimonial, Article, FAQ, Lead, AiConfig, KnowledgeDoc, MediaAsset, AdminUser and AuditLog. Flag seed data as placeholders; do not invent metrics, clients or consent. Never render empty or unpublished sections, social URLs or optional media links.

Homepage: navbar/availability/CTA, hero, stats, projects, guarded AI demo, services, process, about/stack, articles, optional pricing/testimonials/FAQ, final CTA and footer. CMS controls order, headings and visibility. Projects and articles have index/detail pages. Add custom 404, RSS, sitemap, robots, titles/descriptions/canonicals/OG/Twitter and structured data. Enforce alt text, semantic HTML, focus states, contrast and reduced-motion preferences. Self-host subset fonts and locally vendor admin libraries.

Admin: Argon2, Flask-Login, CSRF, secure HttpOnly SameSite cookies, temporary login lockouts, optional TOTP and CLI create-admin. Dashboard counts/placeholders/AI usage, typed CRUD and filters, keyboard/drag reorder, Markdown preview sanitized with nh3, draft preview tokens, Publish, media validation/variants/metadata stripping, leads inbox/notes/CSV, settings/integration readiness, JSON + uploads ZIP backup/import and audit log. Publish must update SSR without rebuilding; public snapshots, short fetch TTL and secret revalidation protect the draft/public boundary.

Public API: home, projects, project detail, articles/pagination/detail, sitemap data, contact, streaming AI and health. Contact validates CMS options, honeypot, exact origin, Turnstile and rates, saves leads, optionally notifies via configured Telegram/SMTP. WhatsApp primary CTA uses CMS number/message; repeat conversion paths and support optional configured analytics events.

AI: exactly one environment-selected allowlisted model behind an adapter. BM25 retrieval over published owner content. First-message Turnstile, IP limits, atomically reserved global daily budget, max 500 input characters/output limit/six turns, immediate kill switch, prompt-injection defenses, no impersonation, clear CMS disclaimer and no conversation persistence. Store usage/cost metadata only. Accessible visible-hydrated island streams tokens and handles offline/budget/verification states.

Deployment: single Ubuntu VPS, Nginx → Node localhost:4321 and gunicorn localhost:8000, direct cached uploads, compression, HTTPS, CSP/nonces/HSTS/other headers, systemd, deploy script, cron DB+uploads backups/retention, least-privilege database access and .env-only secrets. Lock dependencies, run Python/npm audits in CI. Write setup/VPS runbook, admin guide, API and decisions.

Delivery phases: (1) Foundation, (2) Admin, (3) Conversion and AI, (4) Content and SEO, (5) Hardening/deploy, (6) optional EN switch. Test/build/commit each phase. Acceptance targets include local fresh-clone setup, publish within five seconds, honest visibility, 95+ mobile Lighthouse across four categories, bounded AI, working lead notifications, pytest, Playwright desktop/mobile edit/publish/contact and axe. Distinguish verified results from targets or checks blocked by runtime/credentials; never invent passing browser scores or a successful push.
